## 🚀 كيفية الاستخدام

### للتطوير
1. انتقل إلى مجلد `neuaden` (التطبيق الرسمي والوحيد)
2. قم بتثبيت التبعيات: `npm install`
3. قم بتشغيل الخادم: `npm run dev`
4. افتح المتصفح على: `http://localhost:3020`

### للبناء
1. انتقل إلى مجلد `neuaden` (التطبيق الرسمي والوحيد)
2. قم ببناء التطبيق: `npm run build:mobile`
3. قم بمزامنة Capacitor: `npx cap sync`
4. قم ببناء APK: `npx cap build android`

### للتثبيت
1. استخدم ملف `BuiltApp/AdenLive-App.apk`
2. تأكد من تفعيل "مصادر غير معروفة"
3. قم بتثبيت التطبيق
