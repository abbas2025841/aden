# خرائط عدن المحلية - عدن لايف

## 📍 الوصف
خرائط محلية لمدينة عدن للاستخدام بدون إنترنت في تطبيق عدن لايف.

## 🗺️ التغطية
- **المنطقة:** مدينة عدن كاملة
- **الحدود:** 12.7° - 12.9° N, 44.9° - 45.1° E
- **المركز:** 12.8275° N, 45.0367° E

## 📁 هيكل الملفات
```
complete/
├── tiles/           # ملفات البلاطات
│   └── {z}/{x}/{y}.png
├── map-config.json  # تكوين الخرائط
├── aden-landmarks.json # معالم عدن
└── README.md        # هذا الملف
```

## 🔧 التثبيت
1. تحميل ملفات البلاطات من OpenStreetMap
2. وضعها في مجلد `tiles/`
3. تحديث `map-config.json` إذا لزم الأمر

## 📱 الاستخدام
- يعمل بدون إنترنت
- يدعم البحث في المعالم
- يظهر الاتجاهات للمواقع
