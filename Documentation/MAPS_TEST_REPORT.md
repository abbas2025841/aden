## 🐛 المشاكل المحتملة

### 1. خطأ "API_KEY_INVALID":
- **السبب**: مفتاح API غير صحيح
- **الحل**: تحقق من مفتاح API في `.env.local`

### 2. خطأ "API_NOT_ENABLED":
- **السبب**: API غير مفعل
- **الحل**: فعّل Maps JavaScript API في Google Cloud Console

### 3. خطأ "QUOTA_EXCEEDED":
- **السبب**: تجاوز الحد المسموح
- **الحل**: تحقق من حدود الاستخدام في Google Cloud Console

### 4. الخريطة لا تظهر:
- **السبب**: مشكلة في تحميل API
- **الحل**: تحقق من وحدة التحكم للأخطاء
