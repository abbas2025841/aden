# إعادة بناء التطبيق مع آخر التحديثات

## المشكلة

التطبيق يعمل على المنفذ 3020 لكن المتصفح لا يعرض التحديثات الأخيرة المذكورة في CHANGELOG.md.

## الحل المقترح

### 1. إيقاف الخادم الحالي

- إيقاف جميع عمليات Node.js التي تشغل التطبيق
- التأكد من تحرير المنفذ 3020

### 2. تنظيف Cache المتصفح فقط

- **لن نحذف أي ملفات من المشروع**
- سنقوم فقط بإعادة تشغيل الخادم مع تنظيف cache المتصفح
- استخدام Hard Refresh في المتصفح (Ctrl+Shift+R أو Ctrl+F5)

### 3. إعادة تشغيل الخادم

- إيقاف الخادم الحالي برفق
- تشغيل `npm run dev` مرة أخرى على المنفذ 3020
- **بدون** حذف أي ملفات أو مجلدات

### 4. تشغيل الخادم من جديد

- تشغيل `npm run dev` على المنفذ 3020
- الانتظار حتى يبدأ الخادم بنجاح
- فتح المتصفح على `http://localhost:3020`

### 5. التحقق من التحديثات

- فحص الصفحة الرئيسية للتأكد من ظهور التحديثات
- فحص صفحة حراج عدن (AdCard improvements)
- فحص PageNavigator وشريط التمرير
- فحص الوضع المظلم/الفاتح

## الملفات الرئيسية المتأثرة

- `client/dist/` - سيتم إعادة بنائه
- `client/src/` - يحتوي على آخر التعديلات
- `vite.config.ts` - إعدادات البناء
- `server/index.ts` - إعدادات الخادم
