# خطة تنظيف المشروع وإنشاء نقطة استعادة

## المرحلة 1: إنشاء نقطة استعادة (Backup)

### 1.1 إنشاء Git Tag لنقطة الاستعادة

- تنفيذ: `git tag -a v2.24.0-stable -m "نقطة استعادة قبل حذف SourceCode"`
- هذا سيسمح بالعودة لهذه النقطة في أي وقت

### 1.2 التأكد من حفظ جميع التغييرات

- تنفيذ: `git status` للتحقق من عدم وجود ملفات غير محفوظة
- إذا وجدت ملفات غير محفوظة، سيتم حفظها أولاً

### 1.3 دفع التغييرات إلى Git (إذا كان متصل بريبو)

- محاولة: `git push --tags` (اختياري - فقط إذا كان هناك remote)

## المرحلة 2: التحقق من محتويات neuaden

### 2.1 التحقق من الملفات الأساسية

ملفات يجب التأكد من وجودها في `neuaden/`:

- `package.json` - التبعيات والإعدادات
- `client/` - كود الواجهة الأمامية
- `server/` - كود الخادم
- `shared/` - الملفات المشتركة
- `android/` - إعدادات Capacitor
- `CHANGELOG.md` - سجل التغييرات
- `README.md` - التوثيق

### 2.2 مقارنة الملفات مع SourceCode

- التحقق من أن `neuaden/client` يحتوي على نفس الملفات أو أحدث من `SourceCode/client`
- التحقق من عدد الملفات والتحديثات الأخيرة

## المرحلة 3: حذف المجلد القديم

### 3.1 حذف مجلد SourceCode

- حذف: `D:\Projects\AdenLiveApp-Complete\SourceCode`
- هذا سيزيل النسخة القديمة نهائياً

## المرحلة 4: تحديث التوثيق

### 4.1 تحديث README.md في neuaden

- إزالة أي إشارات إلى `SourceCode/`
- تحديث المسارات لتشير إلى `neuaden/` كالمجلد الرسمي
- تحديث تعليمات الاستخدام

### 4.2 تحديث CHANGELOG.md

- إضافة إدخال جديد يوثق هذا التنظيف
- ذكر أن neuaden هو التطبيق الرسمي الوحيد

## المرحلة 5: التأكيد النهائي

### 5.1 حفظ التغييرات

- `git add .`
- `git commit -m "تنظيف المشروع: حذف SourceCode والاحتفاظ بـ neuaden كالتطبيق الرسمي الوحيد"`

### 5.2 إنشاء Git Tag جديد

- `git tag -a v2.24.1-clean -m "التطبيق النظيف - neuaden فقط"`

### 5.3 تقرير نهائي

- عرض ملخص بما تم إنجازه
- توضيح كيفية الاستعادة إذا لزم الأمر

## كيفية الاستعادة في حالة حدوث خطأ

إذا حدث أي خطأ، يمكن العودة بهذه الطرق:

### الطريقة 1: العودة باستخدام Git Tag

```bash
git checkout v2.24.0-stable
```

### الطريقة 2: استعادة من سلة المحذوفات Windows

- إذا تم حذف SourceCode للتو، يمكن استعادته من سلة المحذوفات

### الطريقة 3: استعادة commit سابق

```bash
git log --oneline  # للعثور على الـ commit المطلوب
git reset --hard <commit-hash>
```
